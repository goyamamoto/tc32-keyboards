# CIDOO V65 V3 (`cidoo_v65v3`)

ZMK on the CIDOO V65 V3, a 65% ANSI keyboard with a knob on the Telink TLSR8278. It is the [V75 Pro](../cidoo_v75pro/README.md)'s board with the 65% layout and no mode switch: the same matrix pins, knob, LED drivers, flash layout and ways back. The firmware installs over the USB cable with the update protocol of the keyboard's original firmware, which stays in the other flash slot as the way back. The image to install is the full build ([Build](#build)): wired, Bluetooth and 2.4G chosen by key, the backlight, ZMK Studio, US-JIS, the status display.

| Part | Setting |
|---|---|
| Matrix, columns, rows, knob | As the V75 Pro: columns PB5 PB4 PB2 PB1 PB0 PA4 PA3 PA2 PA1 PD5 PD4 PD2 PD1 PD0 PC7 (active low), rows PC5 PC4 PC3 PC2 PC1 PC0 (active low, pull-up); `cidoo,detent-encoder` on PC6 and PB7, the press is mute |
| Layout | 67 keys and the knob press |
| Link | No mode switch: the power switch only turns the battery on. Fn + Y chooses USB, Fn + Q/W/E Bluetooth, Fn + R the 2.4G link; the choice is kept, and a change restarts the keyboard in the new mode. With the cable in: USB, or the chosen wireless link with the cable bringing power only; without it: the wireless link |
| Backlight | Fn + \ toggles, Fn + ] steps the effect, Fn + Up/Down the brightness, Fn + P and ; the colour; the setting is kept over a power cut; the Tab key's LED blinks when US-JIS is turned on or off |
| Caps Lock LED | As the V75 Pro: the host's Caps Lock lights the Caps keycap white over the effect; nothing while the backlight is off or dark. With US-JIS, Caps Lock is the left Ctrl key, and the light stays on the keycap labelled Caps |
| USB | As the V75 Pro: USB only in the wired mode; Fn + U brings it up in a wireless mode for the host tools and Studio, with no keys over it |
| Battery, sleep | As the V75 Pro |
| Flash | The V75 Pro's layout: this firmware keeps its own data apart from the original firmware's |
| Updates | Over a second USB HID interface ([Firmware updates over USB](https://github.com/goyamamoto/zmk-tc32/blob/main/tc32/README.md#firmware-updates-over-usb)) |
| Going back | The boot guard, Fn + Backspace held 3 s (`&prev_fw`) and Fn + Up held while the keyboard powers on ([The two slots and the way back](https://github.com/goyamamoto/zmk-tc32/blob/main/tc32/README.md#the-two-slots-and-the-way-back)) |
| Studio | ZMK Studio over a USB serial port while USB is up; Fn + Del unlocks it (Fn + Esc is the backtick on this 65%). Keep `&studio_unlock` and `&prev_fw` bound when rebinding keys |
| Layers | Base and Fn (Windows), Mac and Mac Fn: Fn + A Windows, Fn + S Mac, kept over a power cut. The Mac layers have Alt and Cmd swapped and the right Alt a Cmd; the number row gives F1-F12 with Fn on both |
| US-JIS | Fn + Tab toggles it, on the Windows layers only. Caps Lock and the left Ctrl are swapped, and the keys beside Space hold their modifier and tap the IME keys (Alt / Muhenkan and Alt / Henkan on Windows, Cmd / Eisu and Cmd / Kana on the Mac); any of these can be given back in Studio |
| Wireless keys | Fn + Q, W, E: Bluetooth profiles 1-3 (a tap keeps the Bluetooth link and selects the profile, held 3 s it also clears its bond). Fn + R: the 2.4G link (a tap chooses it, held 3 s in it pairs with the CIDOO dongle) |
| Pairing | Secure Connections with Passkey Entry: the host shows a passkey, type its digits on the number row, then Enter (Backspace takes a digit back, Escape gives the pairing up). A host that offers only legacy pairing is refused |

## The status display

Fn + B shows the keyboard's state through the backlight for 3 s (dark when the backlight is toggled off): the battery on 1 to 0, one key per ten percent, green from 50 %, orange from 20 %, red under it, blue while charging; the processor time left over on Z to /, cyan; the Bluetooth profiles on Q, W and E (the selected one green when connected, white while it advertises for a pairing, orange while it looks for its bonded host; other bonded profiles dim blue); the 2.4G link on R (green linked, white pairing, orange looking for the dongle); the Windows or Mac mode on A or S, white.

## Keymap files

- `cidoo_v65v3-layouts.dtsi` and `cidoo_v65v3.keymap` are generated by `gen_v65v3.py` from the keyboard's VIA definition and default keymap (the inputs are not in this repository). Functions this firmware does not have (the logo LED, the Windows key lock, the key scan delay, "desktop light low") are `&none`, and the keymap comment lists them.
- `cidoo_v65v3_ble.keymap` puts the wireless keys on Fn + Q/W/E and Fn + R (the original keymap has them on Fn + Z/X/C and Fn + V, which stay `&none`); `cidoo_v65v3_studio.keymap` adds the backlight keys, Studio, the Mac layers, US-JIS and the status key: the image for a keyboard.

## Build

In a workspace set up as [README.md](../../../README.md#build) describes, from `tc32-keyboards/`:

```sh
./build.sh cidoo_v65v3
```

This is the full build, the image to install, in `<workspace>/build/cidoo_v65v3-studio/zephyr/zmk.ota.bin`. `./build.sh cidoo_v65v3 ble` gives the wireless build without the backlight and Studio.

## Install

**At your own risk.** This firmware replaces the keyboard maker's firmware. Installing it, using it or going back from it can make the keyboard unusable, lose its settings and pairings, or end the maker's warranty. It comes with no warranty of any kind (see the [licence](../../../README.md#licence)) and with no support: nobody, neither the authors nor CIDOO, Telink, the ZMK or the Zephyr projects, can help you or takes any responsibility for what happens to your keyboard, your computer or your data. The way back to the original firmware described here worked on the keyboards it was tried on; that is not a promise that it will work on yours. If you are not prepared to lose the keyboard, do not install this.

Follow [INSTALL.md](../../../INSTALL.md) step by step; it names this board's strings and keys. In short, with the keyboard plugged in:

```sh
python3 ../zmk/tc32/scripts/telink_ota.py check   zmk.ota.bin
python3 ../zmk/tc32/scripts/telink_ota.py flash   zmk.ota.bin --vid 320f --pid 5055 --product "CIDOO V65 V3" --yes
python3 ../zmk/tc32/scripts/telink_ota.py info    --vid 1d50 --pid 615e --product "V65 V3 ZMK"
python3 ../zmk/tc32/scripts/telink_ota.py confirm --vid 1d50 --pid 615e --product "V65 V3 ZMK"
```

Confirm within three boots, after the go-back key (Fn + Backspace held 3 s, then released) and the power-on chord have each taken the keyboard back to the original firmware once and the firmware was installed again. Charge the keyboard before the first install.
